## Полуфинал Роботы в городе

Презентованная программа для полуфинала Роботы в городе.

### Разработка

Все алгоритмы навигации и т.д. реализованы в core/tmp.py. В файлы агентов пишем ```from tmp import *``` и пишем код. При сдаче вместо импорта вставляем код tmp.py.
Если вы сейчас не первом коммите (тег v1.0.0), то внутрь агентов уже вставлен код tmp.py.

### Тестирование

- basic_test.py - заголовочный файл для следующих скриптов. Здесь просто создается объект NavigationSystem. Здесь же можно менять точки и т.д..

- line_png.py - отрисовка линии пути, который построил алгоритм, поверх background.png.

- visual.py - live_png.py + поверх еще отрисовка барьеров, точек и многоугольников. Использовал для того, чтобы понять, какого хрена роботу плевать на окружность.
