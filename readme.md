# Инструкция по использованию ПО Траектория кода 1.2.0

После установки программы вам необходимо открыть её и нажать на кнопку "Импортировать" расположенную в правом верхнем углу. 
В появившемся окне вам необходимо указать путь до папки Robots_in_sity, которую вы можете скачать там же, где скачивали нашу программу.
После вам необходимо выбрать в окне программы появившийся тайл "Роботы в городе" и нажать кнопку "Открыть".

У вас откроется интерфейс для мониторинга работы симуляции, где заранее расставлены мобильные роботы в количестве трёх штук, точки от 1 до 15, а также карта полигона.
Рекомендуется сразу открыть папку Robots_in_sity в стороннем редакторе кода, например Visual Studio Code или pyCharm.
Внутри директории Robots_in_sity находится ряд служебных файлов, но ВАС будут интересовать только файлы названные agent_1_controller.py, agent_2_controller.py, agent_3_controller.py,
находящиеся внутри директории user_scripts. Настоятельно не рекомендуется производить какие либо манипуляции с директориями, удалять, создавать, менять или переименовывать файлы.  

### Разберёмся с тем, что представляет из себя симуляция

Каждый скрипт названный agent_?_controller.py является скриптом управления какой либо конкретной мобильные роботы и вся логика управления должна прописываться только внутри этого скрипта.
В проекте Robots_in_sity уже есть логика написанная внутри скриптов agent_?_controller.py которая служит для демонстрации базового функционала работы мобильных роботов внутри симуляции.
Внутри есть основной класс названный Agent?Controller содержащий все методы и переменные.

Класс содержит несколько служебных элементов, которые так и подписаны "Служебное, не трогать!", их трогать не следует.
Реализовывать логику работы вашего мобильного робота вы можете используя систему координат связанную с метрами, либо связанную с пикселями, для перехода от одной к другой 
внутри класса реализованы методы p2m и m2p.

Внутри класса Agent?Controller реализован метод get_control, который каждый тик (0.01 секунды или 100 герц) отправляет управляющие команды ([throttle, steering]) мобильному роботу.

#### Что такое throttle и steering

throttle это коэффициент мощности движения робота находящийся в диапазоне от -1 до 1. Если вы приравняете его равным 1, то это будет означать, что робот будет двигаться с максимальной своей скоростью вперёд, если поставить коэффициент -1, то с максимальной скоростью назад.

steering это коэффициент мощности для поворота в диапазоне от -1 до 1. Механизм его работы аналогичен работе коэффициента throttle.

#### Как мне отслеживать состояние робота переменных?

Если вы хотите записывать какую либо информацию о дроне каждый тик программы (или реже), то для этого есть специальная переменная log_msg внутри метода get_control, 
внутри которой вы можете передавать любую информацию или переменные. После выполнения симуляции все логи будут находиться внутри файла agent?_controller_log.txt,
находящегося внутри директории user_scripts.

#### Как мне узнать местоположение моего робота на карте и его положение?

Для координат робота есть переменая lns_data, которая хранит в себе данные, полученные с локальной навигационной системы. Эти данные обновляется каждые 10 тиков симуляции. 
Для того, чтобы вытащить из неё информацию об оценке координат робота вам необходимо прописать:
```python
lns_data.get("position_estimate")[0]  # координата X
lns_data.get("position_estimate")[1]  # координата Y
```

Для угла поворота машинки есть две переменные: 
- `orientation_rad` - угол поворота в радианах
- `orientation_deg` - угол поворота в градусах

Поскольку эти переменные получают информацию с комплекса инерциальных датчиков, обновление этих переменных происходит 1 раз в 1 тик работы симуляции.

#### Если я допустил ошибку в написании программы, то как мне это понять?

Если в вашем коде есть ошибка, то вы можете открыть файл `core\python_console.log`, где будет описана ваша ошибка. Если ошибки компиляции не возникает, то этот файл хранит исключительно служебную информацию, которая вам не интересна и не может быть вами использована.

#### Чем я могу пользоваться?

Вы можете писать код только в файлах `agent_?_controller.py`, которые после и будут высланы на проверку жюри. Скрипты `agent_?_controller.py` импортирую в себя информацию из файла `config`, которая находится в переменных:
- `self.waypoints` - информация о точках 1-15 и их координатах в пикселях
- `self.obstacles` - информация о препятствиях (многоугольниках) в пикселях
- `self.barriers` - информация о координатах барьеров в пикселях (для студенческого трека)

Изменять информацию внутри файла `config.py` запрещается, исключением считается только создание барьеров для тренировочных заездов студенческого трека.

Импортировать информацию из прочих файлов или использовать другую информацию (кроме описанной выше и ниже) из файла `config` нельзя. 

#### Как создать барьер?

Внутри переменной `BARRIERS`, которая находится в файле `core\config.py` необходимо указать точку начала и точку конца барьера. Для создания сразу нескольких барьеров достаточно перечислить их через запятую. Пример:

```python
BARRIERS = [
    {'start': [268, 503], 'end': [268, 570]},
    {'start': [874, 478], 'end': [832, 600]},
    {'start': [423, 702], 'end': [494, 702]}
]
```

#### Как мне ускорить/замедлить симуляцию и увеличить/уменьшить её длительность?

Откройте файл `core\config.py` и найдите переменные:
- `TOTAL_SIMULATION_TIME = 40.0` - длительность симуляции в секундах
- `PLAYBACK_SPEED = 6.0` - множитель скорости симуляции (у нас симуляция изначально в 6 раз ускорена)

#### Как мне передавать сообщения между роботами? 

Общение между роботами происходит в рамках файла `conections.txt`. 

Для отправки сообщения от робота необходимо воспользоваться методом `self.send_message()`

Для чтения всех сообщений воспользуйтесь методом `self.read_messages()`

**Примеры:**

Отправка сообщения в `conections.txt`:
```python
self.send_message(f"Agent1: orientation={orientation_deg:.2f}°, time={sim_time:.2f}s")
```

Чтение всех сообщений:
```python
all_messages = self.read_messages()
```

#### Как запустить симуляцию?

Перейдите в основное окно программы и нажмите на значёк проигрывателя (красный треугольничек в левом нижнем углу), после чего
начнётся просчёт математики симуляции и спустя небольшое время вам будет предложено запустить проигрывание.

#### Как будет выглядеть задание этого этапа?

Задача эстафеты формулируется следующим образом:
1. Робот под номером 1 должен доехать до робота номер 2 и сообщить ему об этом через conections.txt
2. Робот под номером 2 должен доехать до робота номер 3 и сообщить ему об этом через conections.txt
3. Робот под номером 3 должен доехать до финиша (Это одна из 15 пронумерованных точек)

В `core\config.py` находится переменная `Task`, внутри которой находится номер финишной точки. Для его получения вы можете воспользоваться методом `Read_Task()`

Начальные положения роботов, номер точки финиша и координаты барьеров (для студенческого трека) выбираются случаным образом!!!

Участники присылают на проверку только скрипты `agent_1_controller.py`, `agent_2_controller.py`, `agent_3_controller.py`. Всё остальное будет проигнорировано организаторами.
